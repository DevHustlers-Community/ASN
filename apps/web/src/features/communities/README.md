# Communities Feature (`src/features/communities`)

**Status:** planned — no implementation yet.

Manages Arabian community spaces, channels, rules, and moderation.

## Scope & Capabilities

1. **Community Types:**
   - `public`: Open membership and discoverable in search.
   - `private`: Requires join request / invite approval.
   - `unlisted`: Accessible via direct invite link only.
2. **Channels System:**
   - Multiple thematic channels per community (text discussions, announcements, media).
3. **Roles & Badges:**
   - Owner, Admin, Moderator, Member.
   - Role badges render with distinctive borders and colors.

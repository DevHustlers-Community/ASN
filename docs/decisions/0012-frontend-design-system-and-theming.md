# 0012 - Frontend design system and theming

- Status: proposed
- Date: 2026-10-24
- Supersedes: -

## Context

The web client (`apps/web`) requires a structured design system and component architecture
that supports multilingual Arabic/English typography, RTL layout flow, multiple surface themes
(including true black OLED), accessible color contrast (WCAG 2.1 AA), and zero external CDN
dependencies.

The design system specification in `docs/architecture/design-system.md` defines the target design.
This ADR formalizes the architectural choices, toolchain standardization, and constraints.

## Decision

- **Toolchain standardization on Bun:** Standardize all frontend development, scripts, and CI
  on Bun v1.4+ (`bun.lock`, `packageManager: bun@1.4.4`). The web client links local packages
  via `workspace:*`.
- **Multi-theme token engine:** Implement surface themes (`oled`, `dim`, `light`) and dynamic
  accent selections (`emerald`, `indigo`, `amber`, `crimson`, `cyan`) via CSS custom properties
  on `document.documentElement` (`data-theme`, `data-accent`).
- **RGB triplets for alpha modifier compatibility:** Define accent and status colors as RGB
  triplets (`--primary-rgb`, `--status-*-rgb`) mapped through Tailwind CSS as
  `rgb(var(--primary-rgb) / <alpha-value>)`. This ensures utilities such as `bg-primary/10` and
  `border-status-success/30` compile correctly in production bundles.
- **Accessible contrast (WCAG 2.1 AA):** Ensure >= 4.5:1 contrast for all text. Provide explicit
  `--primary-foreground` tokens for each accent, raise dark mode `--text-dim` to `#9ca3af`,
  use `#ef4444` for dark mode destructive status, and enforce a 12px (`text-xs`) minimum font size.
- **Zero external CDNs:** Bundle typography locally under `/fonts/` (`IBM Plex Sans Arabic` and
  `JetBrains Mono`) with OFL licenses and local font preload.
- **RTL-first logical CSS:** Mandate CSS logical properties (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`)
  and relaxed line-heights (1.65–1.75) for Arabic body text.
- **Product branding:** Adhere strictly to the product name **ASN** (Arabian Social Network) in UI,
  metadata, and documentation per `docs/GLOSSARY.md`.

## Consequences

- All web client builds, tests, and CI workflows run purely through Bun.
- Production CSS generated by Vite contains all necessary opacity tints and semantic tokens.
- Design specifications serve as target architecture; features without backend contracts remain
  marked as planned.
- No third-party network requests are triggered for fonts or assets.

## Alternatives considered

- **npm/Node toolchain for web:** Rejected to maintain repository consistency with Bun-based TypeScript
  services and prevent lockfile divergence.
- **Literal hex colors without alpha channels:** Rejected because Tailwind drops opacity modifiers
  on non-RGB custom property variables.
- **External CDN fonts (Google Fonts):** Rejected to preserve privacy, avoid telemetry leakage,
  and support offline local development.
